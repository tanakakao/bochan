# `bochan` Theory Reference / 理論リファレンス

The theory documentation is maintained as separate English and Japanese editions.

理論ドキュメントは、英語版と日本語版を別フォルダで管理しています。

| Language / 言語 | Documentation / ドキュメント |
|---|---|
| English | [English theory reference](./en/README.md) |
| 日本語 | [日本語版 理論リファレンス](./ja/README.md) |

The two editions use the same chapter numbers and filenames. Equations, code examples, class names, API names, and implementation paths are aligned so corresponding chapters can be compared directly.

英語版と日本語版では、章番号とファイル名を一致させています。数式、コード例、クラス名、API名、実装パスも対応させています。
