# 対話モード用アイコン

このフォルダに対話モードのアイコン画像を配置すると、次の2か所に表示されます。

- 左メニューの「対話モード」アイコン
- 対話モード内のbochan発言アイコン（従来の `b`）

## 対応ファイル名

次の順番で最初に読み込めた画像を使用します。

1. `icon.png`
2. `icon.svg`
3. `icon.webp`
4. `icon.jpg`
5. `icon.jpeg`

通常は次のパスへ配置してください。

```text
web/public/conversation-mode/icon.png
```

画像が存在しない場合、読み込めない場合、または画像形式が不正な場合は、各表示箇所で従来のアイコンをそのまま表示します。

- 左メニュー: `✦`
- bochanの発言: `b`

## 推奨

- 正方形
- 128 × 128 px以上
- 背景透過のPNGまたはSVG
- アイコン周囲に少し余白を設ける

画像を追加・差し替えた後は、Webアプリを再読み込みしてください。
